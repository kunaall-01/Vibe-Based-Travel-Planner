Vibe-Based Travel Planner

A full-stack personalised travel planning platform that recommends destinations and generates itineraries based on a user's mood, budget, available time and travel preferences.

About the Project

Planning a trip often requires searching multiple websites, comparing destinations, estimating expenses and deciding which places can be visited within a limited time.

Our project aims to simplify this process by providing personalised travel recommendations and suggested itineraries based on user preferences.

Key Features

Mood-based travel recommendations.

Destination selection.

Budget-based filtering.

Duration-based itinerary generation.

Estimated travel expenses.

Place ratings and reviews.

Save, view, update and delete trips.
